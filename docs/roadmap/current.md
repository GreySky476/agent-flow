## 使用说明

新需求到来时，请按以下步骤使用本文件：

1. 在"活跃需求"表中新增行，填写编号、标题、优先级（P0/P1/P2）、状态（TODO/IN_PROGRESS/DONE）、受影响模块。
2. 如果需要详细描述，可在下方添加 `### {编号} — {标题}` 小节，包含：
   - **目标**：要达成的业务/技术目标
   - **验收标准**：可测试的 Done 条件
   - **设计引用**：链接到相关 ADR、模块文档、Schema
   - **关联任务**：链接到 `tasks/` 目录下的任务卡
3. 需求完成后，将条目移至"已完成需求"表。
